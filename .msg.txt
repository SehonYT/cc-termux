Report each model's context so nothing shows as unknown

Every provider showed a 200k window because the gateway's /v1/models emitted no capacity
field at all. With nothing to read the client falls back to its own default, so a 1.05M
model looked like a 200k one and AgentRouter's three models looked unknown.

/v1/models now reports context_length and max_input_tokens per model, taken from the model,
then the provider, or omitted when neither knows. Verified live: 70 of 70 models report a
context length.

AgentRouter publishes no context data anywhere. /v1/models returns only id, object, created,
owned_by and supported_endpoint_types; /api/pricing adds ratios and enable_groups; /v1/model
and /api/models do not serve it. So the values are supplied from each model's own
specification: 1,050,000 context and 128,000 max output for gpt-5.6-sol, gpt-6-astra and
gpt-6.1-sol, all three confirmed against vendor documentation.

The setup flow also persists what it learns: a documented default is used when the API
omits context, and the output cap is carried through with it.

Suite is 337 tests, all passing.
